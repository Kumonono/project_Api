# project_Api

Guide:
-Open CMD and wrote mongosh command in it for the database
-Open the project in Visual Studio and start the API
-Add the frontend's driver path then open the index.html file
-If you don't have an account you have to navigate to the "I forgot my password" function
-You need to give your email, then the system will give you a code and you can write there your new password too
-If you finished with the login you free to go to add, delete or update your events!
